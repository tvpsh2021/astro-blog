A quiet place
for words.

The Astro blog is a text-first journal. Warm off-white, restrained green, thin rules, and generous whitespace keep attention on the writing.

For maintainers This page is a visual reference. The implementation source of truth is src/styles/global.css. Update this guide when the visual rules change.

Page behavior

05 / 06
PageRoutesContent
Homepage/, then /page/2/ and later pages8 posts per page, newest first. Sequence numbers continue across pages. No hero section.
Archive/archive/, then /archive/page/2/ and later pages20 posts per page, grouped by year within each page.
Article/YYYY/MM/DD/slug/Existing WordPress permalink, title, date, categories, rendered content, and tags.

The first list page always uses its short URL. Pagination has page numbers plus previous and next links. The current page uses a filled green square and aria-current="page". Each generated page has its own title and canonical URL.

Maintenance notes

06 / 06
SourceResponsibility
src/styles/global.cssLive colors, typography, layout, responsive rules, and WordPress content styles.
BaseLayout.astroHeader, footer, stylesheet, and document metadata.
HomeListing.astro and ArchiveListing.astroList page structure and headings.
Pagination.astro and pagination.tsNavigation markup and page sizes.

Keep one visible h1 per page. Preserve clear navigation labels, keyboard focus, and readable contrast. Check desktop and small-screen layouts after changing spacing. WordPress HTML has basic styles for headings, images, captions, embeds, lists, and quotes. Legacy codecolorer-container blocks fill the article width, keep line numbers in a separate gutter, and scroll horizontally for long lines; add other plugin-specific styles only after checking an affected article.
